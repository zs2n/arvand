# عرش أرْوَند

لعبة إدارة مملكة وقرارات بأسلوب بكسل آرت، على طريقة Yes, Your Grace.

العب: https://zs2n.github.io/arvand/

## بنية المشروع
- `src/data/` المحتوى: الشخصيات، القضايا، الرسائل، المهام، الكنوز، المراسيم، النهايات. أي تعديل في القصة يكون هنا.
- `src/engine/` المحرك: القاعة، المجلس، الحصار، الموسيقى، الإنجازات.
- `build.py` يجمع الملفات في صفحة واحدة: `index.html` (لـ GitHub Pages).

بعد أي تعديل: `python3 build.py`

إنتاج استوديو قرطاس.
